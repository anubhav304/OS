BEFORE THE ABSTRACTION

A computer is a machine before it is a desktop.

Under every browser, editor, game and terminal sits a collection of physical components doing extremely literal work.

The operating system turns that machinery into something programmers and people can actually use. It manages the processor, memory, devices, files and competing programs without requiring every application to understand the hardware underneath.

The abstraction is useful precisely because the hardware is complicated.

Applications
